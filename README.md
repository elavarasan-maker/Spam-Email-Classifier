# Spam-Email-Classifier
It turns text into numbers with TF-IDF. It learns spam vs. not-spam with Naive Bayes. Streamlit gives you a simple web page for it.

To run it:
Install the libraries: pip install streamlit scikit-learn pandas
Start the app: streamlit run app.py
Open the link it prints, paste a message, and click Check message.
How it works:
It turns text into numbers with TF-IDF.
It learns spam vs. not-spam with Naive Bayes.
Streamlit gives you a simple web page for it.
